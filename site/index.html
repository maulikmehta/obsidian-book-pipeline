AuthorKit™

Your Obsidian vault, print-ready.

A Quarto + Typst build pipeline and Claude Code plugin that takes a book from scene files to a press PDF and a Kindle interior — driven by one small book.yml per title, not a near-identical build script per title.

Built and run by Swati Joshi — 7 titles, 16 live editions across Amazon.com, Amazon.in, IngramSpark and Barnes & Noble, all on owned ISBNs. This is the pipeline behind them.

What you get

/book-new
Scaffolds a book vault — asks for title, format, manuscript status and target channels, then writes the structure.
/book-audit-vault
Checks the vault is sound: book.yml valid, Story/Index.md and Characters/ present, fonts available for the build.
/book-audit-manuscript
Checks the manuscript itself — characters referenced but missing a note, act and chapter drift, first mentions that should be linked.
/book-build
Renders the print PDF with bleed, trim and cover-spread lockup, and preps the Kindle interior from the same source.

Install

/plugin marketplace add maulikmehta/authorkit
/plugin install authorkit

Free, MIT licensed. Source on GitHub.

Requirements

  • Quarto — renders .qmd to Typst to PDF
  • Python 3
  • ImageMagick, for cover cropping
  • Your own licensed fonts, dropped into pipeline/fonts/
