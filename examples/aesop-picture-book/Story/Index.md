# The Tortoise and the Hare — spread index

A picture book has no acts or chapters, so this list is flat. Each file
declares `type: scene` in its own frontmatter, which is what makes it a
scene regardless of nesting depth — the novel demo gets the same result
by nesting two levels deep instead.
