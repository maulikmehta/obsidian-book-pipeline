# Optional shared fonts

**Most books do not need this folder.** A typeface is part of a book's
design, so the normal home is a `fonts/` folder beside that book's
`book.yml`, which takes precedence over anything here.

This shelf exists for the one case where it earns itself: a house face used
across a whole catalogue, kept in one place instead of copied per title.

Nothing is tracked in git either way — fonts are usually licensed per seat
and must not ship in a public repo.

Set the face in the book's own `_quarto.yml`. The shared one names no
typeface on purpose.
